# ФинПиксель — сжатая лекция (30–40 мин)

## Аудитория

~90% женская, работа со сменным / неровным доходом, часто с долей наличных.  
Тон: взрослый, прямой, без морали и без упрощения. На слайдах профессию не выпячиваем — говорим языком кэша, пиков, рабочих трат и резерва. В зале можно быть конкретнее.

**Что цепляет зал:** средняя из 3–6 месяцев вместо «лучшей пятницы»; корзины жизнь / работа / кайф; % с хорошей смены в резерв; сутки паузы перед «вложи».

## Источники

- ФинПиксель дни 1, 3, 4  
- Скам / пирамиды / инфоцыгане — **MBS день 1**  
- Каркас курса — [krichevskiy.ru/finpixel](https://krichevskiy.ru/finpixel/)

## Как открыть

`finpixel-lecture/index.html` в браузере.  
`→` / пробел — вперёд, `←` — назад, `F` — полный экран.

## Тайминг (~39 мин по счётчику внизу, 26 слайдов)

| Слайды | Блок | Акцент для зала |
|--------|------|-----------------|
| 1–5 | Вход | Хук «пассивный», специфика неровного дохода, карта |
| 6–12 | Контроль | Учёт кэша, утечки, 3 корзины трат, подушка 9–12 мес |
| 13–15 | Защита | 3 звонка, пирамида, «знакомый предложил», инфоцыгане |
| 16–20 | Архитектура | Корзины денег, покемоны, облигации/акции/недвижка кратко |
| 21–23 | Конструкция | Формула капитала, 5 вопросов, взносы с хороших месяцев |
| 24–26 | Закрытие | Регламент, 7 действий, финальная фраза |

## Если останется 5 минут

Кейс из зала: «хороший месяц 400+, плохой 80 — куда класть?» → сразу четыре корзины + % в подушку.
